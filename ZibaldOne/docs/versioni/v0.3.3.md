# ZibaldOne 0.3.3 — Backup e diario al sicuro

- Al primo avvio l'app genera una password principale: tu scegli solo le regole. Salva il foglio di recupero e tienilo al sicuro.
- I backup sono file chiusi del tutto: senza password o codice di recupero non si legge niente. In Mnemosyne trovi la lista «I tuoi backup».
- Anche il diario sul dispositivo è cifrato. All'avvio puoi sbloccarlo con impronta, volto o blocco schermo.
- Scegli dove tenere i backup e chi li gestisce: l'app, tu o tutti e due.
- Su Android «Scarica» mette il nuovo APK nella cartella Download e apre l'installazione.
- Di notte l'app ti accompagna con un messaggio e un modello per le notti insonni. In Kosmesis scegli i colori dell'app e l'icona.
- La home mostra le otto aree a tutta larghezza; in Collezioni «Tutte» sta al centro.
- Se la cartella dei backup non è scrivibile, l'app lo spiega e ti dice che il lavoro è salvo.

Per chi aggiorna: al primo avvio l'app chiede il nuovo consenso e poi la password principale; chi aveva una passphrase la inserisce una volta per passare alla password. Tieni un backup prima di aggiornare. Il file `zibaldone.db` diventa `zibaldone.zbdb`.
